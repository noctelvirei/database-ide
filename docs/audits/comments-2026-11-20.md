Source revision: `d96562b` (main). Every plain comment in the repository's tracked Rust files was read beside the code it describes and given one disposition.

## Scope

- Covered and fully audited: every `//` and `/* */` comment in the 153 tracked `.rs` files under `crates/`, found with a Rust-aware lexer (strings, raw strings, char literals and nested block comments are not comments), plus the comments in `Cargo.toml` and `scripts/check-rust-layout.mjs`.

- Not covered: `.claude/skills/verify/*.ps1` (the verify skill's judge files, which change only in a pull request the owner merges), `*.sql` test data, and Markdown.

## Pending

Two comments stay: B308 in `Drop for Server` in `crates/test-servers/src/mysql.rs` and B321 in `Drop for Server` in `crates/test-servers/src/postgres.rs`. Each sits between two nested `if`s, and Clippy skips its `collapsible_if` lint when a comment is there. Deleting either fails `cargo clippy -D warnings` unless the two `if`s are merged, and this audit changes no code. `scripts/comment-allowance.json` allows exactly these two. Ticket DAT-82 (#66) merges the `if`s, deletes the comments and adds their rule (keep a server's folder when shutdown fails, since a live server may still use its files) to ADR 0005.
